这一部分文档面向的是教师，助教，学生以外的第三方用户，比如说课业帮扶先锋岗的成员。

其特点是：

- 他们只需要查看成绩，没有修改成绩的需求
- 他们的学在浙大账号，没有访问该课程的权限
- 他们可能只关心重点关注学生列表的情况

viewer这个role，旨在解决这个问题。

# 如何获得一个viewer账号

请联系一位助教，参考 [如何为你的课程添加一个新的成员](./add-new-user-for-your-course) 完成账号的创建。

助教可能会给你提供一个链接，需要你参照[我收到了别的助教发来的这个链接，我该怎么办？](./https://atasaas.5dbwat4.top/docs/add-new-user-for-your-course#%E6%88%91%E6%94%B6%E5%88%B0%E4%BA%86%E5%88%AB%E7%9A%84%E5%8A%A9%E6%95%99%E5%8F%91%E6%9D%A5%E7%9A%84%E8%BF%99%E4%B8%AA%E9%93%BE%E6%8E%A5%E6%88%91%E8%AF%A5%E6%80%8E%E4%B9%88%E5%8A%9E)完成账号配置

# 使用这个账号，我可以做什么

整体设计上，你可以查看所有的实验列表，可以查看学生名单以及他们各个实验的得分，还可以看到助教给的评语或附言，但是无法做修改。

- 选择“实验列表”栏目，在此页面，你可以看到实验列表以及对应的时间
- 点击任意一个实验，你可以看到这个实验的分值以及学生的成绩和评语。
- 选择“分数列表”栏目，在此页面，你可以看到所有学生的所有成绩，你可以点击第一列中学生的姓名进入“学情分析”页面。
- 课程设置和个人设置页面对应着一些设置（还有废话文学说是）

# 我是课业帮扶先锋岗，我只关心我的重点关注对象

目前的重点关注对象列表，由**助教**根据上级下发的各类文件确定并录入。

【后续的版本会提供逐人的重点关注对象编辑能力】

建议先点击课程设置，选中“在 nav 中显示「重点关注对象」”这个switch。

选择“重点对象”栏目可以看到所有的重点关注对象，以及成绩。同样可以点击第一列的学生姓名进入“学情分析”页面。
