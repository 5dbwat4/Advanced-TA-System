# 角色

系统使用 `User.role` 表示账号身份，共四种：

| role | 含义 | 访问范围 |
| --- | --- | --- |
| `TA` | 助教 | 后台日常教学功能 |
| `TEACHER` | 教师 | 暂与助教权限相同 |
| `VIEWER` | 观察者 | 独立面板建设中；当前不能进入助教 / 教师后台 |
| `STUDENT` | 学生 | 学生控制台 |

`VIEWER` 与 `STUDENT` 都由后端白名单限制可访问的接口；`TA` / `TEACHER` 才能访问后台接口、MCP 与实时协作能力。

# 账号从哪里来

系统**没有公开的自助注册入口**。账号由课程名单或助教在课程内创建：

- 助教/教师账号：采用类似“裂变增长”的方式，见下文。
- 学生账号：随课程学生名单产生。学生首次登录后自行设置用户名。
- 观察者账号：由管理员预置，后续接入独立面板。

如果你还没有账号，请联系课程助教/管理员。
