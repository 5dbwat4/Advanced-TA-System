# 验收、排队与群面

本页介绍现场验收相关的三组功能：**答题计时**、**排队验收**（含叫号与插队）和**把题目发给学生**，以及它们与**群面**（多学生并行验收）的配合方式。

## 答题计时

助教的验收页会自动记录每位学生的答题用时，不需要手动开始或暂停。

- **计时起点**：在「定位学生」中选中某位学生时开始计时，同时进入「展示 demo」。
- **显示位置**：选中学生后，验收页顶部操作区会出现 ⏱「答题时间」芯片，在第 3/4/5 步（展示 demo、现场抽题、录入成绩）都可见；第 5 步「录入成绩」的学生信息条右侧还有一个紧凑版。
- **格式**：不足 1 小时显示 `mm:ss`（如 `03:25`），超过 1 小时显示 `h:mm:ss`（如 `1:05:09`）。
- **保存时记录**：点「保存并下一位」会把本次用时一并提交，成功后提示形如 `已保存 · 张三 · 用时 03:25`。
- **查看历史用时**：「更多 → 现在谁正在验收」的「最近保存」列表里，每条会追加 `· 用时 mm:ss`。
- **清零时机**：保存后、返回「选择实验 / 定位学生」、切换实验时清零；重新选中学生后重新计时。
- **群面**：每个 tab 各自独立计时，切换 tab 不会重置，只有换实验 / 保存 / 回到选人步骤才清零。

> 用时只是记录与参考，不影响分数计算。

## 排队验收

学生可以在学生端「排队验收」页面对当前开放验收的实验**加入 / 取消排队**；助教在验收页查看队列、叫号、调整顺序。队列按「实验 + 班级」共享，**学生不能选择助教**。

### 三种队列状态

| 状态 | 含义 | 触发 |
| --- | --- | --- |
| 排队中（未被叫号） | 已加入队列，还没被叫 | 学生加入 / 助教手动加入 |
| 已叫号 · 助教名 | 助教提醒该学生准备验收 | 助教点「叫号」 |
| 验收中 · 助教名 | 助教正在验收该学生 | 助教在验收页选中该学生（自动） |

助教保存该学生该实验的成绩后，队列记录**自动删除**（验收完成）。

### 助教端：排队情况

验收页顶部（单机版在偏好按钮左侧，群面版在其 actions 首位）有「排队情况」按钮，右上角数字是排队人数（已选实验时显示该实验人数，未选时显示全班人数，>99 显示 `99+`）。

打开后：

- 按实验分组，**当前实验组置顶并高亮**；组头显示实验编号标题、人数、各状态小计。
- 每行显示：`#位次`、头像、姓名、学号、状态徽标，以及 `排队 14:03 · 已等待 12 分钟`（已叫号追加 `叫号 14:15`，验收中追加 `开始 14:18`）。
- 操作按钮：
  - **叫号**（铃铛）——提醒学生准备验收。学生端会显示「已被 XX 提醒准备验收」，开通浏览器通知还会收到推送。
  - **撤回叫号**——仅自己叫的显示；别人叫的可直接改成自己叫号。
  - **上移 / 下移**——调整该实验内的顺序（首尾自动禁用）。失败会提示「队列顺序已变化，请刷新后重试」，刷新即可。
  - 正在验收中的行不提供叫号/撤回。
- 组头「添加」：内联搜索本班学生（姓名 / 学号 / 拼音，已在队列中的会被排除），点击即可加入队尾。队列为空时也有「手动添加学生」入口。
- 点击某一行会把该学生「定位」到验收流程：切到对应实验并把学号预填进搜索框；**不会自动选中学生**，仍需助教线下叫人后自己点选，避免误保存。

> 队列是全班共享的：多名助教看到的是同一个队列，任意一位助教保存成绩都会把该学生移出。

### 学生端：排队验收

学生登录后左侧「排队验收」（`/student-console/queue`）只显示**本人**的信息，看不到队列人数、位次或其他同学：

| 状态 | 页面显示 | 可执行操作 |
| --- | --- | --- |
| 未排队 | 「未排队」 | 加入队列 |
| 排队中（未被叫号） | 状态 + 排队时间 + 已等待多久 | 取消排队 |
| 已被助教叫号 | 「已被 XX 提醒准备验收」+ 提醒时间 + 该助教当前情况 | 取消排队 |
| 验收中 | 「验收中」+「助教 XX 正在验收你」 | 无（等助教保存） |
| 已完成验收 | 「已完成验收」 | 重新排队 |

被叫号时还会显示提醒你的那位助教的实时情况：

- 「XX 正在验收其他同学」或「XX 暂未开始验收」；
- 「还有 N 位同学也被 XX 提醒、正在等待验收」（N > 0 时显示）。

页面每 10 秒自动刷新，切回标签页时立即刷新；被叫号、开始验收、验收完成自动移出都会有提示。

如果助教中途离开验收页或切换了学生，状态会恢复为「已叫号」或「排队中」，**排队位置不会丢失**。

## 把题目发给学生

为了让同学能在自己的电脑上先思考，助教抽题后题面会实时同步到学生端（**只发题面，不含答案**）。

- 助教在「现场抽题」步骤抽出题目后，系统自动把这几道题（通常是 1–2 道）推送给该学生；
- 学生端「排队验收」页面顶部会出现「本次验收题目」，按 1、2 编号显示完整题面；学生概览页也会出现「助教已推送本次验收题目，点击查看」的提示条；
- 以下情况会自动收回，学生端立即不再显示：
  - 助教点击「保存并下一位」（验收结束）；
  - 助教把抽到的题清空 / 重新抽题前；
  - 助教切换学生、切换实验或返回选人步骤；
  - 助教关闭页面或对应的群面 tab。
- 学生端网络轮询最长 10 秒内生效。

> 题目只包含题干，学生看不到参考答案。

## 与群面的配合

「群面」（`/console/checkoff-multi`）可以同时开最多 8 个验收 tab，每个 tab 是独立的一次验收：

- **每个 tab 独立计时**：tab 条下方显示各自的「答题时间」。
- **每个 tab 独立排队联动**：在某个 tab 中选中学生，该学生队列状态变为「验收中 · 你的名字」；该 tab 保存或关闭后恢复。
- **排队面板共享**：群面页顶部的「排队情况」可以看到全班队列；点击队列中的学生时：
  - 如果该学生已经在某个 tab 中验收，直接切到那个 tab；
  - 否则优先使用同一实验且空闲的 tab，没有则复用空白 tab，再没有就新建 tab；
  - 并把该学生学号预填进该 tab 的搜索框（仍需线下叫人后自己点选）；
  - 已满 8 个 tab 时会提示先关闭一个，不会强行清空你正在验收的内容。
- **题目同步按 tab 隔离**：每个 tab 抽到的题只发给对应的那位学生。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 学生说看不到排队入口 | 确认账号角色是学生、已绑定班级，且实验处于开放验收期（已发布且未过验收截止） |
| 学生看不到「本次验收题目」 | 助教需先进入「现场抽题」并抽出题目；最多等 10 秒刷新 |
| 叫号后学生没反应 | 学生页面 10 秒轮询；推送需要学生在设置中开启浏览器通知 |
| 顺序调整失败 | 队列被其他人改过，刷新后重试 |
| 保存后学生还在队列 | 正常情况会自动移出；若网络异常，助教可在队列面板刷新确认，或让学生自行取消 |
| 群面里找不到「排队情况」 | 群面页顶部操作区最左侧的列表图标按钮 |
