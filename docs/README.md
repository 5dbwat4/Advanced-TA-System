# 计算机系统课程助教系统 · 前端使用手册

本手册面向三类使用者：

- **助教（TA）/ 教师**：管理实验、题库、验收、实验报告、成绩和课程设置。
- **学生**：查看实验时间线、成绩、报告批改结果和附言。
- **验收从机使用者**：在手机或第二台电脑上配合主设备完成现场验收。

> 说明：本手册只覆盖前端页面与交互。账号、名单和成绩均以当前所登录课程的数据为准。
> 手册中的截图来自本地演示环境，其中的姓名、学号、分数均为演示数据。

## 快速开始

1. 打开 `http://localhost:5173`，使用课程提供的账号登录。
2. 首次登录按页面提示完善用户名（学生还需要确认班级），可同时设置密码或绑定通行密钥。
3. 进入「总览」确认右上角课程是否正确；如有多个班级，使用顶部课程选择器切换。
4. 助教按「实验 → 题库 → 验收 → 实验报告 → 分数和名单」的顺序完成一次教学闭环。
5. 学生通过「学生端」查看实验时间线、成绩和报告批改详情。

## 界面通用操作

| 操作 | 位置 |
| --- | --- |
| 切换课程/班级 | 顶栏右侧「选择班级」 |
| 切换深色/浅色主题 | 顶栏右侧太阳/月亮图标 |
| 折叠/展开侧边栏 | 顶栏左侧按钮 |
| 退出登录 | 侧边栏底部头像右侧按钮 |
| 返回上一级 | 页面左上角「返回」 |
| 页面内快速定位 | 右侧「本页目录」（设置、课程设置等长页面） |

## 演示边界

本手册**没有演示**向学在浙大推送/回写数据。页面中出现的「去推送成绩」「向上游推送成绩」「同步成绩」等入口仅用于说明位置和用途，实际推送请按课程管理员的流程操作。
